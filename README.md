# 정동진 보리 차실 (jeongdongjin)

BORIH MORNING의 온라인 차실입니다. 정동진 절벽 위 3D 차실에서 함께 앉아 차를 우리고, 정동진의 실제 해를 따라 하늘이 바뀝니다.

- 주소: https://borih-official.github.io/jeongdongjin/
- 구성: `index.html` + 홈 화면 아이콘 파일(`manifest.webmanifest`, `icon-180.png`, `icon-192.png`, `icon-512.png`). Three.js r128 + Supabase(Realtime, 방명록 표 `guestbook`), 모두 CDN
- 버전: 화면 왼쪽 위 로고 옆의 작은 `vN` 번호 = 코드 안의 `APP_V`

## 운영 정책

- **공개 방, 익명 입장.** 링크를 아는 누구나 이름만 정하고 들어옵니다. 서버 검증은 없습니다.
- 대신 화면 쪽에서 막는 것: 다른 사람이 보낸 값은 정해진 값만 받음(자세·동작·차 종류·좌석 번호·글자 수), 메시지의 링크 주소 자동 삭제, 한 사람당 메시지 5초에 한 번, 초당 신호 수 제한, 좌석은 먼저 앉은 사람 우선.
- 이름·메시지 출력은 모두 `esc()`로 글자 처리합니다. 고칠 때 빠뜨리지 마세요.
- Supabase는 Realtime 채널과 표 두 개(`guestbook` 방명록, `cup_log` 마신 잔)만 씁니다(스토리지 없음). 표에는 Row Level Security가 켜져 있습니다.
  - 방문자(anon): 쓰기와 읽기만. 고치기·지우기 불가. 기기 번호(`device`)와 `hidden` 칸은 읽을 수 없습니다.
  - 저장소에서 막는 것: 이름 12자·한 줄 80자, 링크·도메인 금지, 같은 기기 30초에 1개·하루 20개, 차실 전체 1분 60개.
  - 숨기기: Table Editor → guestbook → 해당 줄의 `hidden`을 true로. 숨긴 매듭은 화면에서 사라지고 기록은 남습니다.
  - `cup_log`: 방문자는 넣기만 가능(읽기·고치기·지우기 불가). 같은 기기 6초에 1잔·하루 300잔, 차실 전체 1분 300잔. 화면은 `cup_stats(장소)` 함수로 이 차실 누적 잔수, 오늘 잔수, 모든 차실 누적으로 이름별 잔 수(최대 300명)만 받습니다(기기 번호는 나가지 않음). Supabase 보안 점검에 이 함수가 '로그인 없이 실행 가능'으로 뜨는데, 일부러 연 것입니다.
- 클라이언트에는 공개용 키(anon/publishable)만 넣습니다. `service_role` 키는 절대 넣지 않습니다.
- 입장 화면에 "이름과 걷는 모습, 남긴 메시지는 지금 차실에 있는 모든 분에게 보여요" 안내가 있습니다. 기기에 남는 값: 이름(`bm.nick`), 기기 번호(`bm.id`), 고른 차(`bm.tea2`).

## 설정 (index.html 위쪽 `settings`)

| 이름 | 뜻 |
|---|---|
| `PLACE` | 이 차실의 장소 이름 |
| `OPEN_END` | 문 닫는 시각. 지금 2026-11-17 00:00 KST. 이후에는 입장 대신 "새로운 일출 장소로 옮겨갑니다" 화면만 나오고 연결하지 않음 |
| `NEXT_PLACE`, `NEXT_URL` | 다음 차실 이름과 주소. 비워두면 "보리 인스타그램에서 알려드릴게요" |
| `STEEPS` | 차별 우림 시간(초). 표가 끝나면 60초씩 |

## 정해둔 규칙

- 머리 위 (잔 수 = 이 브라우저에 쌓인 모금 ÷ 5, `bm.sips`, 방문할 때마다 이어짐): 4잔 꽃봉오리(조금씩 부풂) → 8잔 금빛 꽃 '뿅' → 15잔 노을빛 → 22잔 새벽빛 → 30잔 이삭 '짜잔'(꽃은 밑동에 남음) → 이후 한 잔에 한 알씩 16알이면 투둑, 다시 6알부터. 방명록 위 내 기록에 지금 단계와 다음 단계까지 남은 잔 수.
- 한 모금: 보듬이를 들고 있으면 약 24초마다 저절로 한 모금, '한 모금' 버튼으로도 한 모금. 둘 다 셉니다. 한 잔은 다섯 모금.
- 우림 시간(세차 없음): 녹차·백차·우롱·홍차 10→15→20→30→45초, 이후 60초. 보이차 15→20→20→25→30→40→50초, 이후 60초. 근거: Yunnan Sourcing 공부차 가이드. 보이차 세부 초는 가이드에 없어 보리가 정함.
- 다시 우리기: 같은 차는 2탕부터 텀블러 물만 붓고, 차를 바꾸면 차통에서 새 찻잎부터.
- 찻상 배치(앉은 사람 기준): 뒷줄 왼쪽부터 숙우 · 차통 · 다관, 앞줄 가운데 보듬이, 오른쪽 끝 텀블러.
- 차를 우리고 따르는 동안 화면은 움직이지 않습니다(처음 시점 그대로).
- 소리: '명상 음악' 버튼. 잔잔한 화음 + 아주 멀리 파도, 60초 반복. 싱잉볼은 음악을 켤 때 처음 한 번만 울림. 파일 없이 화면이 직접 만들며, 들어온 뒤 약 2.5초에 미리 만들어 두어 누르면 바로 나옵니다.
- 가을 풍경(9~11월): 해송이 중심, 단풍나무·은행나무가 섞인 그림책풍 나무. 섬과 뒷산도 같은 작은 나무 숲. 마당은 늦가을 톤 낙엽이 수북하고, 걸으면 발밑 잎이 차여 흩어짐(다른 사람 발밑도). 내 걸음에만 아주 작은 '바스락' 소리.
- 사진(인증샷): '사진' 버튼은 걸을 때나 앉았을 때 언제든. 3:4, 1080×1440(폰 900×1200). 앉아 있으면 내 자리 앞쪽 비스듬한 구도, 걸을 때는 보이는 화면 그대로. 이름표·버튼은 들어가지 않음. 글자: BORIH MORNING / 정동진 보리 차실 / 지금 마시는 차(작게, 마실 때만) / 차를 바꿨으면 '오늘의 찻자리 · 녹차 → 홍차' / 날짜 · 일출 시각, 오른쪽 아래 @borih.official. 버튼 둘: '사진 저장'(공유 창 → 이미지 저장)과 '친구에게 보내기'(사진 + "정동진 보리 차실에서 차 한 잔 했어요. 같이 앉아요." + 차실 주소). 공유 창을 열고, 공유가 끝나거나 취소하면 차실 화면으로 돌아옴. 공유 창이 없는 브라우저(카카오톡·인스타 안에서 연 링크 등)는 '사진을 길게 눌러 저장' 안내만 하고 페이지를 떠나지 않으며, 친구에게 보내기는 차실 주소만 보내거나 복사함. PC는 파일 내려받기 후 자동으로 닫힘. 사진은 기기에서만 만들어지고 어디에도 올라가지 않음.
- 가벼움: 들어온 뒤 약 1.5초부터 3초 동안 화면 속도를 재서, 1초 40장 아래면 한 단계씩 낮춤. 1단계: 그림자 끄기, 화질 1.25배까지. 2단계: 화질 1배, 낱장 낙엽·나무 잎 절반(바닥 낙엽 그림은 그대로). 고른 단계는 기기에 기억(`bm.q`)하고, 다음 방문 때 빠르면 한 단계 올려 봄. 걷거나 화면을 만지거나 차를 우리는 중이 아니면 1초 30장으로 쉬어 감. '가볍게 보기'(아래 패널, `bm.lite`)를 켜면 자동 단계와 상관없이: 화질 0.75배, 그림자 끔, 낱장 낙엽·나무 잎 절반, 떨어지는 잎 끔, 먼 산·섬 나무 절반, 늘 1초 30장.
- 다정(茶情) 나무 방명록: 아래 패널 '내 기록' 버튼(예전 '인사' 자리) → 오늘 마신 차·그동안 쌓인 찻잔(차별)·머리 위 단계·순례 도장. 방명록 창에는 내 기록이 없음. '방명록' 버튼 → 위에 다정 나무 이야기, 한 줄(80자) '걸기'. 마당 오른쪽 해송(x 4.7, z 8.6) 가지에 최근 50개가 카드로 걸리고, 카드를 누르면 글이 보임. 나무 밑 '다정 나무' 푯말(차로 나눈 정을 한 줄씩 걸어 두는 방명록)을 누르면 "다정 나무에는 최근 방명록 N장이 카드로 매달려 있어요 · 지금 한 줄 남겨 보세요"와 '한 줄 남기러 가기' 버튼(방명록이 바로 열림). 안내 창·카드 글은 한 번 누르거나 마당의 빈 곳을 누르면 바로 닫힘(그냥 두면 저절로 닫힘). 전체는 방명록 목록에서 '더 보기'(30개씩). 장소(`place`)별로 저장되어 다음 차실도 같은 표에 쌓임.
- 다정 나무 길 안내: 마당을 걸을 때 발 앞 약 2m부터 푯말까지 땅 위에 금빛 화살표 줄이 이어지고 빛이 나무 쪽으로 흐름. 화살표를 누르면 푯말 앞까지 걸어감. 푯말 바로 앞(약 2m 안, 앞쪽)에 서면 안내글이 저절로 뜨고, 3.4m 넘게 멀어졌다 다시 오면 또 뜸.
- 기록 이어가기(이 브라우저에만): 이름(`bm.nick`), 옷 색(`bm.robe`), 다녀간 날·마신 차 잔 수·해돋이 순례 도장(`bm.rec`). 다른 날 다시 오면 "다시 오셨네요 · N번째 찻자리예요". 머리 위 꽃도 이어서 자람(`bm.sips`). 첫 화면(이름 입력)에 짧은 안내: 같은 기기·같은 브라우저면 이어짐, 사파리면 사파리로, 카톡·인스타 안이나 시크릿 모드는 새로 시작, 홈 화면 추가 권장. 첫 화면을 거치지 않고 들어온 기존 방문자에게만 자세한 안내 창이 한 번 뜸(`bm.kept`). 방명록 아래 '기록 이어가기 안내'로 언제든 다시 볼 수 있음.
- 홈 화면 아이콘은 사파리 안에서 열리게(`display: browser`) 해 두었습니다. 따로 앱처럼 열리면 아이폰이 사파리와 다른 저장 공간을 써서 기록이 이어지지 않기 때문입니다.
- 함께 마신 차: 오른쪽 위 찻잔 아이콘 카드('N잔 · 함께 마신 차 · 보리 차벗')(이 장소 누적, 보듬이에 따를 때마다 1잔). 누르면 '보리 차벗': 모든 보리 차실(정동진과 다음 일출 차실)에서 쌓인 찻잔을 이름별로 합쳐 많은 이름부터 전부(최대 300명, 매일 다시 시작하지 않음), 순위 번호 없이. 위에 이 차실 누적 잔수와 내 잔 수. 차벗 목록은 날짜와 상관없이 그동안 쌓인 잔으로, 이름 전부(최대 300명) 보여요. '오늘 마신 차'는 각자의 기록(방명록 위 내 기록)에만 나와요(`bm.rec.today`). 같은 이름은 합쳐 셈(누가 같은 이름을 쓰면 그 사람 잔도 더해짐). 1분마다, 다른 사람이 따를 때 몇 초 안에 새로 고침.
- 자리: 기록(이름·꽃·잔 수·도장)은 이어지지만 방석은 이어지지 않음. 다시 들어오면 늘 마당에서 시작. 창을 닫으면 바로, 다른 앱으로 가거나 폰을 잠가 10분이 지나면 방석을 내어 줌("오래 비우셔서 방석을 다른 분께 내어 드렸어요 · 기록은 그대로예요"). 새 버전으로 자동 새로고침될 때만 2분 안에 같은 방석으로 돌아옴.
- 차실: 네 면 모두 유리(가는 나무 틀), 출입문도 유리문. 지붕은 두꺼운 평지붕(약 50cm, 짙은 나무 테두리)에 사방 처마를 깊게 내고, 처마 밑과 천장은 따뜻한 나무 널. 벽 위와 지붕 사이 바다 쪽·양옆은 유리 띠. (비교용으로 주소 끝에 `?roof=a` 짙은 징크 외쪽 경사, `?roof=c` 밝은 징크를 붙이면 다른 지붕을 볼 수 있음) 방석은 엇갈림 배열(지그재그): 앞줄 7자리, 둘째 줄은 반 칸 밀린 6자리, 셋째 줄 7, 넷째 줄 6. 처음 3줄(20자리). 20자리가 다 차서 21번째 분이 들어오는 순간 넷째 줄이 나타나고, 최대 4줄(26자리). 바닥은 평평함.
- `?layout=row`: 예전처럼 나란한 7자리 줄(비교용). `?layout=zig`: 엇갈림 + 계단식 바닥 **실험** 화면. 정식 기능 아님.

## 방명록 엑셀로 받기

1. supabase.com → 프로젝트 `borih-morning` → 왼쪽 **SQL Editor**
2. 아래를 붙여 넣고 **Run**
   ```sql
   select id as 번호,
          to_char(created_at at time zone 'Asia/Seoul','YYYY-MM-DD HH24:MI') as 남긴시각,
          place as 장소, name as 이름, message as 남긴말, tea as 차, hidden as 숨김
   from guestbook
   order by created_at;
   ```
3. 결과 표 위의 내보내기(Export / Download) → **CSV**
4. 엑셀에서 한글이 깨지면: 엑셀 **데이터 → 텍스트/CSV에서**로 열고 인코딩을 UTF-8로 고르거나, 구글 시트에서 파일 → 가져오기로 여세요.

### 마신 잔 기록 받기
```sql
select to_char(created_at at time zone 'Asia/Seoul','YYYY-MM-DD HH24:MI') as 시각, place as 장소, name as 이름, tea as 차
from cup_log order by created_at;
```

- [ ] 방명록: 매듭 걸기 → 나무에 걸리는지, 다른 기기에서도 보이는지, 30초 안에 두 번 안 걸리는지, 매듭·푯말을 누르면 글·안내가 보이는지
- [ ] 기록: 다음 날 다시 들어오면 'N번째 찻자리', 옷 색 그대로, 방명록 위 내 기록에 마신 차 잔 수
- [ ] 홈 화면에 추가 → 아이콘으로 열었을 때 같은 기록이 보이는지
- [ ] 함께 마신 차: 보듬이에 따르면 오른쪽 위 숫자가 늘고, 다른 기기에서도 몇 초 안에 늘어나는지, 눌러서 순위가 보이는지
- [ ] 메시지 남기기, 링크가 지워지는지, 5초 안에 두 번 보내지지 않는지
- [ ] 명상 음악 켜기/끄기(아이폰 무음 모드에서도)

- [ ] 버전 숫자를 올려 배포 → 열린 화면이 한 번만 새로고침되고 같은 자리로 돌아오는지
