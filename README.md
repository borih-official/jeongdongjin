# 정동진 보리 차실 (jeongdongjin)

BORIH MORNING의 온라인 차실입니다. 정동진 절벽 위 3D 차실에서 함께 앉아 차를 우리고, 정동진의 실제 해를 따라 하늘이 바뀝니다.

- 주소: https://borih-official.github.io/jeongdongjin/
- 구성: `index.html` 한 파일 (Three.js r128 + Supabase Realtime, 모두 CDN)
- 버전: 화면 왼쪽 위 로고 옆의 작은 `vN` 번호 = 코드 안의 `APP_V`

## 운영 정책

- **공개 방, 익명 입장.** 링크를 아는 누구나 이름만 정하고 들어옵니다. 서버 검증은 없습니다.
- 대신 화면 쪽에서 막는 것: 다른 사람이 보낸 값은 정해진 값만 받음(자세·동작·차 종류·좌석 번호·글자 수), 메시지의 링크 주소 자동 삭제, 한 사람당 메시지 5초에 한 번, 초당 신호 수 제한, 좌석은 먼저 앉은 사람 우선.
- 이름·메시지 출력은 모두 `esc()`로 글자 처리합니다. 고칠 때 빠뜨리지 마세요.
- 지금은 Supabase **Realtime 채널만** 쓰고, 테이블·스토리지는 쓰지 않습니다. 테이블을 추가하게 되면 Row Level Security부터 설계합니다.
- 클라이언트에는 공개용 키(anon/publishable)만 넣습니다. `service_role` 키는 절대 넣지 않습니다.
- 입장 화면에 "이름과 걷는 모습, 남긴 메시지는 지금 차실에 있는 모든 분에게 보여요" 안내가 있습니다. 기기에 남는 값: 이름(`bm.nick`), 기기 번호(`bm.id`), 고른 차(`bm.tea2`).

## 설정 (index.html 위쪽 `settings`)

| 이름 | 뜻 |
|---|---|
| `PLACE` | 이 차실의 장소 이름 |
| `OPEN_END` | 문 닫는 시각. 지금 2026-11-17 00:00 KST. 이후에는 입장 대신 "새로운 일출 장소로 옮겨갑니다" 화면만 나오고 연결하지 않음 |
| `NEXT_PLACE`, `NEXT_URL` | 다음 차실 이름과 주소. 비워두면 "보리 인스타그램에서 알려드릴게요" |
| `STEEPS` | 차별 우림 시간(초). 표가 끝나면 60초씩 |

## 정해둔 규칙

- 새싹: 들어올 때마다 처음부터. 10모금에 알 6개짜리 이삭이 맺히고, 한 모금에 한 알씩 16알까지 차면 털려 떨어지고 다시 6알부터.
- 한 모금: 보듬이를 들고 있으면 약 24초마다 저절로 한 모금, '한 모금' 버튼으로도 한 모금. 둘 다 셉니다. 한 잔은 다섯 모금.
- 우림 시간(세차 없음): 녹차·백차·우롱·홍차 10→15→20→30→45초, 이후 60초. 보이차 15→20→20→25→30→40→50초, 이후 60초. 근거: Yunnan Sourcing 공부차 가이드. 보이차 세부 초는 가이드에 없어 보리가 정함.
- 다시 우리기: 같은 차는 2탕부터 텀블러 물만 붓고, 차를 바꾸면 차통에서 새 찻잎부터.
- 찻상 배치(앉은 사람 기준): 뒷줄 왼쪽부터 숙우 · 차통 · 다관, 앞줄 가운데 보듬이, 오른쪽 끝 텀블러.
- 차를 우리고 따르는 동안 화면은 움직이지 않습니다(처음 시점 그대로).
- 소리: '명상 음악' 버튼. 잔잔한 화음 + 아주 멀리 파도, 60초 반복. 싱잉볼은 음악을 켤 때 처음 한 번만 울림. 파일 없이 화면이 직접 만들며, 들어온 뒤 약 2.5초에 미리 만들어 두어 누르면 바로 나옵니다.
- 가을 풍경(9~11월): 해송이 중심, 단풍나무·은행나무가 섞인 그림책풍 나무. 섬과 뒷산도 같은 작은 나무 숲. 마당은 늦가을 톤 낙엽이 수북하고, 걸으면 발밑 잎이 차여 흩어짐(다른 사람 발밑도). 내 걸음에만 아주 작은 '바스락' 소리.
- `?layout=zig`: 엇갈림+계단식 좌석 **실험** 화면. 정식 기능 아님.

## 배포

1. 고친 `index.html`을 저장소에 올립니다(같은 이름으로 덮어쓰기).
2. `APP_V` 숫자를 하나 올립니다. 열려 있는 화면들이 1분 안에 한 번 새로고침해 같은 자리로 돌아옵니다(버전마다 한 번만).
3. GitHub Pages 반영까지 1~10분 걸릴 수 있습니다.

## 일출·일몰 계산 확인

계산은 간이 태양 위치 공식(고도 −0.833° 기준)입니다. 공개 자료와 비교:

| 날짜 | 차실 계산 | 비교 자료 | 차이 |
|---|---|---|---|
| 11월 2일 | 06:50 / 17:25 | 바다타임 강릉 06:50 / 17:25 | 0분 |
| 11월 3일 | 06:51 / 17:24 | 바다타임 강릉 06:51 / 17:24 | 0분 |
| 11월 30일 | 07:19 / 17:06 | 바다타임 강릉 07:20 / 17:06 | 1분 |

몇 분 안쪽이므로 "실제 해를 따른다"는 표현을 유지합니다.

## 올린 뒤 확인 목록 (폰 1대 + PC 1대, 두 창 동시)

- [ ] 이름 입력 → 마당 → 출입문 → 빈 방석 앞 '여기 앉기'
- [ ] 다른 기기에서 들어온 사람이 새로고침 없이 보이고, 나가면 사라짐
- [ ] 같은 방석을 두 기기에서 거의 동시에 누름 → 먼저 앉은 쪽이 남음
- [ ] 차 고르기 → 차 우리기(차통 → 텀블러) → 종소리·메시지 반짝 → 숙우 → 보듬이에 따르기 3번
- [ ] 같은 차로 2탕: 차통 없이 텀블러 물만 / 차를 바꾸면 차통부터
- [ ] 한 모금·자동 모금으로 찻물이 줄고, 10모금 이삭, 21모금 털림
- [ ] 메시지 남기기, 링크가 지워지는지, 5초 안에 두 번 보내지지 않는지
- [ ] 명상 음악 켜기/끄기(아이폰 무음 모드에서도)
- [ ] 다른 창을 봐도 자리가 유지되는지
- [ ] 버전 숫자를 올려 배포 → 열린 화면이 한 번만 새로고침되고 같은 자리로 돌아오는지
- [ ] 마당을 걸을 때 낙엽이 흩어지고, 폰에서도 끊김 없이 걷히는지
- [ ] 화면 크기별로 글자·버튼이 겹치지 않는지
